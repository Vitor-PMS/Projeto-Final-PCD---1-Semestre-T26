  Esse é o meu projeto final do primeiro semestre de Práticas em Ciência de Dados. Meu projeto se baseia em uma biblioteca musical, capaz de manipular músicas através de uma interface. Cada música pode receber até 6 atributos: Nome, Artista, Gênero, Ano de Lançamento, Nota, Sei Tocar (o atributo "Sei Tocar" diz respeito a se você sabe tocar uma determinada música)
